Signed Certificates

Tamper-evident, independently verifiable attestations for every scan we deliver. metatron-cert/1 — an open format.

Why

Reports say "trust us". Certificates let you check. Every certificate is a plain JSON file containing our findings for a specific token at a specific moment — signed with our Ed25519 key and bound to a hash of the raw scan evidence. Change one character anywhere, and the signature breaks.

  • Findings can't be silently edited after delivery
  • Anyone can verify — no account, no API key, ~50 lines of code
  • The format is open: any scanner can issue certificates with its own key; you choose whose key you trust

Verify one yourself

Works on the sample certificate or any certificate you receive from us:

git clone https://github.com/invisiblemonsters/token-launch-scan
cd token-launch-scan/attest
pip install cryptography
python verify_certificate.py sample/certificate-sample.json

→ prints PASS — signature valid plus the claims, timestamp, and evidence hash. Tamper with any field and it prints FAIL.
